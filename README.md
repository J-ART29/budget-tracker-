# Budget Tracker

## Project Description

Budget Tracker is a simple web page for viewing example expenses and adding
expenses to the table during the current browser session.

## Files

- `index.html`: Contains the page structure, expense form, and expense table,
  including the initial example expenses.
- `style.css`: Defines the color palette, typography, form and table styling,
  spacing, borders, and card design.
- `script.js`: Validates submitted expenses and adds them to the table.
- `README.md`: Documents the project and its files.

## Design Choices

- Colors: Navy blue, teal green, white, and soft gray.
- Typography: Manrope for headings and DM Sans for body text, loaded from
  Google Fonts when an internet connection is available.
- Forms: Consistent input spacing, borders, focus states, and rounded corners.
- Table: Styled headers, cell padding, alternating row colors, and hover
  effects.
- Layout: Responsive width, spacing, and rounded card sections.

## Technologies Used

- HTML
- CSS
- JavaScript
- Google Fonts

## How to Run

Open `index.html` in a web browser. An internet connection is needed to load
the Google Fonts. Expenses added through the form are not saved after the page
is refreshed.
